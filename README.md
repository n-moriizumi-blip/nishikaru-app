# nishikaru-kensa-app

西軽精機の統合Webアプリ「品質保証課アプリ」(GitHub Pages + GAS API構成)。既存の[勤怠申請アプリ](https://github.com/n-moriizumi-blip/nishikaru-sinsei-app)と同じ構成を踏襲している。

## 構成(2026-08-12)

- ルート `index.html`: `./app/index.html` への自動転送のみ(旧URLブックマーク維持用のスタブ)。
- `app/`: 品質保証課アプリ本体(選択画面+2機能)。PWAの`scope`をこのフォルダに絞っているのがポイント(下記「PWAのscopeについて」参照)。
  - `app/index.html`: アプリ選択画面。ここから2つの機能へ分岐する。
  - `app/defect-report/`: 品質不具合報告(社内不良・差し戻し品のクイック入力)。バックエンドは`検査不具合報告\品質不具合管理システム\WebApi.gs`(ローカル)、デプロイ済み。
  - `app/qr-inspection/`: 検査担当割付・検査開始前保留のQR受付。`?func=assign` または `?func=inspectionHold` を付けて開くと、アプリ内の選択画面を飛ばして直接その機能へ進む(選択画面はこの形でリンクしている)。
  - `app/manifest.json`・`app/icon-192.png`・`app/icon-512.png`・`app/favicon.svg`: 品質保証課アプリのPWA関連ファイル。
- `qr-cleaning/`: 洗浄工程(洗浄待機・洗浄完了のQR受付)。品質保証課アプリとは完全に別の単独PWA(独自の`manifest.json`・アイコンを持つ)。

`qr-cleaning`・`app/qr-inspection`のバックエンドは、`進捗状況照会`スプレッドシートに紐づくGAS(`コード.gs`、ローカルは`進捗状況照会\コード.gs`)。

アイコン(`app/icon-192.png`・`app/icon-512.png`)は`勤怠管理システム\資料\品質保証課アプリ.png`(ローカル)を透過処理して書き出したもの。`qr-cleaning/icon-192.png`・`qr-cleaning/icon-512.png`は同フォルダ内の`洗浄工程ロゴ.png`を透過処理して書き出したもの。

### PWAのscopeについて(2026-08-12追記)

当初、品質保証課アプリの`manifest.json`をリポジトリ直下に置いていたため、`scope`が既定でサイト全体(`/`)になり、`qr-cleaning/`もそのスコープに含まれてしまっていた。この状態だと、洗浄工程のページを開いてもChromeが「新規インストール」ではなく「(スコープ内の)品質保証課アプリで開く」を案内してしまい、洗浄工程だけを個別にホーム画面へインストールすることができなかった。
対応として、品質保証課アプリ関連ファイルを`app/`フォルダへ移動し、`manifest.json`に明示的に`"scope": "./"`を設定してスコープを`app/`配下だけに絞った。これにより`qr-cleaning/`がスコープの外になり、独立したPWAとしてインストールできるようになった。**旧URL(リポジトリ直下)を触ったことがある端末で、既に品質保証課アプリをインストール済みの場合は、この変更を反映するために一度アンインストールしてから再インストールする必要がある**(スコープはインストール時点のものがキャッシュされるため)。
